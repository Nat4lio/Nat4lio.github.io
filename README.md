# João Natálio — Personal Portfolio

Live at: [https://nat4lio.github.io/](https://nat4lio.github.io/)

My personal website, built to showcase my work as a Computer Engineering graduate from the University of Coimbra. It includes detailed sections on my academic and personal projects, ranging from distributed search engines (Java RMI) to a custom Java-like compiler (C/LLVM) and Web Application Penetration Testing.

## Built With
* Semantic HTML5
* Vanilla CSS3 (Custom properties, CSS Grid/Flexbox, Keyframe animations)
* Vanilla JavaScript (Intersection Observers, requestAnimationFrame)
